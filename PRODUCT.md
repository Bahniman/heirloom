# Product

Heirloom is a working concept prototype for portable organizational memory. Its Python library demonstrates memory records, role-scoped recall, provenance fields, supersession, and JSON export/import. The web page contains a local fixed-corpus simulation of role-based retrieval and lifecycle events.

The site is not connected to an identity provider, assistant, external MCP server, or customer system. The sandbox demonstrates the product idea; it does not provide production authorization, cryptographic key revocation, or vendor interoperability. The MCP server and embedding retrieval are roadmap items. Do not imply customer adoption or validated outcomes.

Preserve the explicit prototype status, open-source license, source links, cited evidence, and candid limitations.
